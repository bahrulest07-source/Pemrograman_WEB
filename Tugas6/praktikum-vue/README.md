# Catatan Buku

Aplikasi daftar bacaan sederhana menggunakan Vue 3 dan Vite. Tambahkan judul,
pilih kategori, dan tandai buku yang sudah selesai dibaca. Jumlah buku selesai
dihitung secara reaktif.

## Menjalankan aplikasi

```sh
npm install
npm run dev
```

## Build produksi

```sh
npm run build
```
