# Soda Senja

Aplikasi jualan minuman soda sederhana menggunakan Vue 3, Vue Router, dan Pinia.

## Menjalankan aplikasi

```sh
npm install
npm run dev
```

## Fitur

- Halaman menu di `/` dengan empat pilihan minuman soda.
- Halaman keranjang di `/cart`.
- Tombol beli menambahkan produk melalui `useCartStore`; jumlah, subtotal, dan badge navigasi diperbarui secara reaktif.
- Jumlah produk dapat diubah dan produk dapat dihapus dari keranjang.
